AirPlayTray — Stream Windows PC Audio to HomePod / AirPlay 2

An open-source TuneBlade alternative when legacy AirPlay 1 streaming breaks on HomePod OS 27 and newer HomePod firmware updates. Capture the default Windows playback device via WASAPI loopback and stream to HomePod, HomePod mini, or AirPlay 2 speakers from the system tray.

开源免费的 TuneBlade 替代方案：解决 HomePod 升级新版系统后无法推流的问题，支持将 Windows 10 / 11 电脑系统声音实时推送至 HomePod / HomePod mini / AirPlay 2 音箱，无需虚拟声卡，提供免装 Python 便携版。

Download v0.3.0 Portable ZIP / 下载便携包 v0.3.0 Release Notes / 更新说明 View Source on GitHub 简体中文文档

Why AirPlayTray

  • Uses pyatv's AirPlay 2 audio channel instead of legacy AirPlay 1 protocols.
  • Captures Windows system sound directly through WASAPI loopback without virtual cables.
  • Zero-config first run when a single HomePod is discovered, or switch speakers right from the tray menu.
  • Adjust live AirPlay volume from the tray with presets and +/-5% controls while keeping the current session connected.
  • Releases idle speakers after 60s of silence and automatically reconnects when audio resumes.

核心特性

  • 采用 pyatv AirPlay 2 音频通道，解决传统工具在新版 HomePod 上的兼容断流问题。
  • 通过 Windows WASAPI 环回采集整机声音，免装虚拟声卡。
  • 支持便携压缩包免 Python 启动、中英文自适应右键菜单、三色状态图标与静音自动释放。
  • v0.3 支持托盘音量档位、加减 5% 和静音恢复，直接调节当前 AirPlay 会话。
  • 适合作为 TuneBlade 替代工具用于日常电脑看视频、听音乐推流到 HomePod。

Quick Start / 快速上手

  • Download AirPlayTray-win-x64.zip from v0.3.0 Releases (no Python required), extract to a writable folder, and run AirPlayTray.exe.
  • To upgrade, exit the old instance and copy its data/config.json into the new package's data folder. 升级时先退出旧实例，将公开版旧包的配置复制到新包，以保留音箱和音量选择。
  • Or run from source on 64-bit Python 3.9–3.12 following README.md / README.zh-CN.md.

v0.3 validation / 验证范围

54 automated tests pass on Windows Python 3.9 and 3.12. Live HomePod volume adjustment, mute, and restored audio were confirmed. The full idle-volume wakeup sequence and app-restart restoration still need hardware verification. No separate Python-free Windows machine or second speaker was available.

54 项自动测试通过，已实测 HomePod 调音、静音与恢复声音。待机修改音量后的完整唤醒流程和程序重启恢复仍待真机补测。无独立的无 Python 电脑或第二台音箱可测。音量菜单支持默认 direct 通道，pipe 实验通道暂不可用。
